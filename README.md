## Новая структура книг
- `/` — главный сайт
- `/books/` — выбор возраста
- `/books/1-3/` — книги 1–3
- `/books/3-7/` — книги 3–7
- `/books/7-10/` — книги 7–10
- `/play/` — выбор книги для игр
- `/play/ocean/` — меню игр «Океана идей»

## Как самой заменить книгу на возрастной странице
Например:
`books/3-7/index.html`

Найдите:
`<!-- EDIT BOOK CARD START -->`

Внутри карточки:
1. Картинка:
`<img src="../../assets/book-covers/ocean.svg" ...>`

Можно заменить путь на свою JPG/PNG, например:
`<img src="../../assets/book-covers/my-book.jpg" ...>`

2. Название:
`<h3>Океан идей</h3>`

3. Описание:
`<p>...</p>`

4. Чтобы добавить новую книгу, целиком скопируйте блок от:
`<!-- EDIT BOOK CARD START -->`
до:
`<!-- EDIT BOOK CARD END -->`

и вставьте рядом.

## Куда положить новые картинки
Проще всего:
`assets/book-covers/`

После этого указывать файл в `src`.

## Проверка локально
В папке сайта:
`python -m http.server 8000`

Открыть:
`http://localhost:8000`
